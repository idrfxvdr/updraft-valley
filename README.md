An original flight game: fly a bush plane over a river valley, through ring runs, supply drops and a ridge crossing, with fuel, damage, a lit instrument panel and graded landings. Static files under `game/` (three.js vendored), no build step, no network request.

Run locally: `node serve.ts` and open http://localhost:8080. License: MIT.
